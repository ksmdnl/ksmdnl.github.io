Developing perception systems for autonomous driving has not been a trivial task. Besides of having been one of the central topics in the community, there are just so many scenarios in the streets to consider in order to secure the system's safety. And while sensor devices are getting better and cheaper, a system that robust against noise or corruption needs to be studied further. To locate objects and boundaries (lines, curves, etc.) in street or traffic scenes a typical approach is to build a system that transforms the input into something more practical to analyse. Object detection locates existing objects in a scene and assigns a category to each identified object, while semantic segmentation deals with a pixel-level classification, producing a mask of certain classes.

During my bachelor study I was working with Andreas Bär in computer vision for autonomous driving. One of the crucial things to care for in AD is how the performance of a vision model, e.g., semantic segmentation, object detection, object tracking, depth estimation, etc., can be tracked or quantised or estimated. Semantic segmentation, for instance, assigns each pixel on a camera a class and generates the user or planner a segmentation mask. A group of pixels can be classified as pedestrian, others as cars and so on.

Quantising and estimating the performance of the segmentation model, i.e., how good is the prediction quality in each given time?, would be a good start. In Andreas Bär's work, it extends the prediction head of segmentation model with a reconstruction head that reconstructs the input image. It works by training only to reconstruct the image given the representation of the input image that was only trained for segmentation and then to assume a correlation between the segmentation and the reconstruction since both share a representation module or encoder. So a bad representation should mean a bad segmentation, formulated as a regression problem, and since we can compute the quality of the reconstructed image (e.g., PSNR, SSIM), we could estimate the segmentation performance. So the trained model is calibrated on the validation dataset, i.e., the PSNR and the Mean Intersection over Union (mIoU) to get the regression parameters and apply these parameters on unseen data in online mode. Basically, estimating the mIoU using the PSNR. What about on object detection? The setup above works because the assumption holds, i.e., high correlation between the two predictions. I extended the framework to object detection model to estimate the Mean Average Precision (mAP) using the PSNR. We observed a low correlation between the two and sure enough the estimation was way off. So we take a step back focus on other things. So, mIoU(PSNR) works given the assumption. Naturally, it makes sense to try to improve on the correlation, because high correlation -> better estimate. Initially, the reconstruction module was initialised randomly. Here we initialised it using the weights of the segmentation head. We can control how much the transfer is so we can see a gradient. Further, we add the segmentation exposure to the reconstruction module by doing feature fusion on different prediction step. Also here we can control how much fusion is done. The work (CVPR Workshop 2023) shows that the estimate gets better the more exposure, either by parameter initialisation or feature fusion or both, the reconstruction module get, which again confirmed our hypothesis and aligned with our assumption.
